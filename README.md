# Rishikesh Prajapati — Portfolio Website

A responsive personal portfolio website built with:
- HTML5
- CSS3
- Bootstrap 5.3
- Vanilla JavaScript
- Bootstrap Icons

## Run locally
1. Extract this folder.
2. Keep `assets/profile.jpg` in the `assets` folder.
3. Open `index.html` in a browser.

No build tools are required.

## Customize
- Edit personal text in `index.html`.
- Edit colors/layout in `style.css`.
- Add projects inside the `#projects` section.
- Replace `assets/profile.jpg` if you want a different profile photo.

The Bootstrap CSS/JS and Google Fonts are loaded from CDN, so an internet connection is needed for those external assets.
